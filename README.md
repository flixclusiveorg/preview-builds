This repository hosts pre-release builds of [Flixclusive](https://github.com/flixclusive/flixclusive) for early testing and feedback.

> [!WARNING]
> Preview builds are **unstable** and may contain bugs, incomplete features, or breaking changes. Use at your own risk and do not rely on these for daily use.

## Installation

1. Go to [**Releases**](../../releases)
2. Download the latest `.apk` for your preferred build type
3. Enable **Install from unknown sources** on your device if prompted
4. Install and launch

## Reporting Issues

Found a bug? Please open an issue on the [Flixclusive repo](https://github.com/flixclusiveorg/Flixclusive/issues)

> Please check first if the issue already exists before opening a new one.
